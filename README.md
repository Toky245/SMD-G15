# SMD-G15

Digital marketing strategy project: customer segmentation, campaign performance analysis, churn/CLV prediction and an interactive Streamlit dashboard. Master 1 group project.

| Membre | Modules | Dossier |

| Lalatiana | M7 | `strategie/m7_strategie` |
| Chateau Brillant | M1 + rapport | `strategie/m1_enjeux`, `rapport` |

## Règles

- Ne jamais modifier `data/raw/` : ce sont les données originales du prof.
- Tout le monde travaille sur les fichiers de `data/processed/`.
- Les résultats destinés au dashboard vont dans `data/results/` en CSV.
- Les graphiques exportés vont dans `figures/`.
